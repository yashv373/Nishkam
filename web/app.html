Connect your machine

RTL problems run fully in your browser. Physical design (LibreLane on gf180) needs real tools, so it runs on your own computer through a small helper program. The website never gets your files; the helper only accepts this page and a secret token.

  1. Start the iic-osic-tools Docker container.
  2. Run the helper: 
    python runner/nishkam_runner.py
  3. Open the link it prints. This page connects on its own.
